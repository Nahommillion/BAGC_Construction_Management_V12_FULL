# BAGC V38 – Resource, Subcontractor, Attendance & Finance Control

## Resource Request hierarchy
Project requester -> Office Engineer -> Office Head -> Source Project Manager -> matching Head Office functional responsible person -> final registration.
The receiving project's Project Manager is never an approval stage.

Functional HO routing: Fuel -> Fuel/Equipment function; Material -> Store; Machinery -> Machinery/Equipment; Manpower -> HR; Expense -> Finance; Design -> Design; Procurement/Subcontractor -> Contract Administration/Procurement.

## Subcontractor
Contract signing date, contract details, subcontractor project team contacts, BOQ lines with quantity/rate, daily BOQ execution and work-linked expenses. Subcontractor daily progress and expenses are shown in the main project's Daily Report.

## Attendance / HR / Finance
Project permanent and temporary manpower attendance is centralized for HR. Head Office department/team/higher-official attendance is recorded separately. Project payroll is generated for a period and sent to Finance with PENDING / IN_PROGRESS / PAID status.

## Corporate Finance
Finance/General Manager/Operational Manager/Super Admin can see all-project income vs expense. Project Managers retain project-level financial visibility through Daily Report and Project Finance. Weekly/monthly period controls and charts are included.
